# 阅读与 AI 助读交互优化清单

范围：本轮合并到 `main` 的 4.0.1 候选代码。`main` 更新不等于 GitHub Release/BRAT 更新；发布状态以 PR、CI 和 Release 页面为准。

## 设计原则

阅读是主任务；AI 是可随时求助的侧栏。内容、来源和保存结果必须可信，不能让用户靠猜测判断是否保存成功、问的是哪本书。保留自定义提示词、模型设置、流式 Markdown 和原页 PDF，不增加额外的标题生成请求。

## 后续独立任务，不混入这次发布

- [ ] 手机实机：软键盘、长按原生选区、双指缩放、横竖屏及 VoiceOver/TalkBack。桌面窄屏不等同于手机验收。
- [ ] 多主题与可访问性专项：高对比、200% 字体、完整屏幕阅读器流程、RTL 和完整键盘遍历。
- [ ] 草稿跨重启持久化：需明确本地保存/同步与清理策略；本轮只做面板内按书隔离。
- [ ] 对话搜索、逐条编辑、分支重试与导出整段会话；当前继续保留轻量每书线程和单回答保存。
- [ ] 模型生成的语义标题：当前使用即时本地候选；如需额外生成，要让用户明确选择成本和数据发送。
- [ ] 超长 PDF 增量分页、更多真实文档压力测试；OCR/图片问答仍是单独的产品及隐私范围。
- [ ] 双设备同时离线修改与同步冲突合并、外部笔记重命名关联修复；不能承诺任何同步服务永不丢数据。

这张清单覆盖本次审计的主要阅读、输入、来源、保存、失败恢复、设备和发布路径，不把尚未验证的项目标为已完成。
