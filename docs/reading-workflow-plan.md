# 阅读工作流：开发清单与实现说明

本轮从已合并的 4.0.1 源码开始，在 `codex/reading-workflow` 开发。初始范围是本地实现、安装及验收；后续维护者已要求更新 GitHub 展示，当前通过功能分支与 PR 发布。下方“未推送”等描述为对应验收阶段的历史快照，不代表当前 GitHub 状态；正式 Release 独立处理。

## 交互结构

- 顶部：返回书库、书名、本书笔记、AI、专注、阅读设置、更多。计时器未启动时收起，更多菜单保留启动入口。
- 底部：目录、搜索、上一处/下一页、章节与进度（点击定位）、下一页。PDF 使用原文件页码，EPUB 使用章节与百分比。
- 导航面板桌面贴近底部，手机使用底部面板；悬停、聚焦、面板展开时不得自动隐藏导航。
- 不新增 Agent 工具权限，不改变模型、自定义提示词或现有书籍/划线数据。

## A. 导航与搜索

- [x] A1 目录和搜索移至同一底栏，共享桌面/移动入口；操作保持键盘可达。
- [x] A2 EPUB 主位置标签改为章节与百分比；PDF 保留原页码；定位弹窗支持百分比和现有页码。
- [x] A3 中文单字搜索；180ms 防抖、结果上限提示、输入法组合期间不误跳转。
- [x] A4 连续搜索：Enter 下一处、Shift+Enter 上一处、上下方向键选结果、Esc 关闭并归还焦点。
- [x] A5 搜索结果精确到匹配文字偏移，同段多次命中可区分；PDF 标注原页，EPUB 标注章节。
- [x] A6 保留查询和结果列表；第一次离开正文记录返回点，连续查看命中不覆盖这个返回点。

实现：抽出可测试的搜索模块；正文匹配使用 Range 跨内联节点定位。浮层覆盖不参与正文排版，避免打开导航引发阅读位置变化。

## B. AI 来源与保存

- [x] B1 文案统一为“本轮不附加原文”；说明旧对话仍含历史来源，新对话才隔离历史。
- [x] B2 回答保存可选独立笔记或追加到本书笔记；追加保留完整 Markdown，不走划线导出路径。
- [x] B3 保存去重到回答级；本书笔记中用不可见标记防止重试重复追加，不覆盖用户正文。
- [x] B4 可验证引用回跳：只为实际出现在已发送上下文中的引文提供入口，再在原书核验定位；不接受模型自报页码作为证明。
- [x] B5 保留自定义提示词与 `/`；快捷提问直接显示，不因已有对话或生成中自动折叠；来源保持简短摘要。

实现：来源引用以原文核验和文本锚点为准，不修改模型提示词、不额外请求模型。无法验证、原文件已变动或已删除时提示无法定位，不猜测位置。

## C. 草稿与对话记录

- [x] C1 按书保存草稿到插件独立本地文件，最多 30 本、每本最多 20,000 字符；不加入同步设置数据。
- [x] C2 输入防抖保存，关闭时刷新；发送成功清除已发送草稿，失败恢复，生成期间的新草稿不被覆盖。
- [x] C3 可清理本书草稿；清空不会删除对话或选文；存储失败给出反馈。
- [x] C4 历史支持标题/书名搜索、重命名；用户改名后自动保存不覆盖标题；本书/全部筛选保留。

说明：本地文件不会由插件主动同步，但第三方同步若包含整个插件目录，仍可能复制该文件。用户手动删文件、换设备不保证恢复。草稿按书隔离，不新增线程级复杂草稿树。

## D. 位置标记与界面减法

- [x] D1 新增可命名的书内位置标记，支持 EPUB 文本锚点和 PDF 原始页码，不需要划线或创建笔记。
- [x] D2 标记列表支持跳转、重命名、删除确认；保存在插件设置中，重启可恢复。
- [x] D3 未启动计时器不常驻；启动后显示，暂停保留恢复入口。
- [x] D4 收起重复位置数字，常用快捷问题保持直接可见；PDF 隐藏字体/行距/重排设置，EPUB 不显示 PDF 缩放。
- [x] D5 本轮不做 OCR、多代理、终端工具、复杂对话目录及跨书语义检索。

## E. 验收

- [x] 模块与真实控制器回归：搜索偏移/单字/键盘、连续返回、追加去重、引用验证、草稿防丢失、历史改名和位置标记规范化。
- [x] 全量测试、i18n、ESLint、生产构建、安装哈希检查。
- [x] 真实 Obsidian：桌面及窄阅读区，导航/搜索/返回、保存弹窗、草稿关闭重开、格式差异。
- [x] 仅测试自建临时记录；不删除用户已有笔记或会话，不改模型凭据；测试文件放回收站，恢复原书位置与设置。
- [ ] 手机物理设备的键盘/长按/触控验收单列，不用桌面模拟冒充。

### 边界与待验证

- 手机物理设备未验收，不能把桌面窄阅读区当作触控/软键盘验收。
- 引文入口只识别可在已发送来源中核验的引号或引用块，最多 5 条；原书无法唯一匹配时展示搜索，让用户确认，不猜页码。当前不是任意回答段落的全自动证据标注。
- 导航点击与视口重排同时发生时仍需专项压力测试；本轮跳转验收以布局稳定后的位置为准。
- 草稿为插件独立本地文件，不主动同步；第三方同步整个插件目录时仍可能复制它。损坏文件会保留副本并暂停覆盖。
- 本轮未改变 ACP 权限、模型、提示词或发起真实模型请求；流式请求的失败/重试/输入法由现有及新增控制器测试覆盖。
