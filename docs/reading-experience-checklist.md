# 阅读体验优化开发与验收清单

范围：EPUB/FB2 重排阅读、PDF 原页阅读、桌面 AI 助读与移动端共享交互。本文保留第一轮本地验收记录；用户随后授权合并到 GitHub main，新增交互及发布清单见 [交互优化清单](interaction-polish-4.0.1.md)。

## A. 上下文可信度

- [x] 翻页、滚动及重排稳定后更新当前页来源；检查实际 CSS 动画状态，不读取动画中间帧。
- [x] 当前页跟随、选文固定、用户移除来源三种状态明确；自动同步不能覆盖选文或重新附加被移除的来源。
- [x] 发送前刷新当前页并固定来源；生成期间切换页面不修改已发送问题，滚动阅读不会因发送而自动跳屏。
- [x] 更新来源仅重绘来源区域，保留草稿、历史阅读位置与展开状态。
- [x] PDF 默认全文，扫描 PDF 边界不变；历史来源不随页面变化。移除后提供“重新引用原文”。

## B. 阅读空间与连续定位

- [x] 增加显式专注阅读入口及退出入口；临时收起两侧栏，退出、切换任务或关闭阅读器时恢复原状态。
- [x] 保留 Obsidian 原生侧栏宽度和拖动能力，不改写用户布局；移动端保留对话框，桌面并排空间不足时可用专注阅读。
- [x] 重排前保留段落、文字偏移和视口位置；连续尺寸变化串行合并，不允许旧布局覆盖新布局。
- [x] 字体、字号、窗口宽高和阅读模式变化后恢复锚点；滚动模式保留可见文字行偏移，分页模式保持目标文字所在页。
- [x] 首次开书恢复与重排互斥；加载/重排期间的滚动回调不写入进度。
- [x] 工具栏显隐不占正文布局空间；专注模式隐身时仍有独立退出按钮。

设计调整：检查本地 Obsidian 类型声明后，没有采用未公开的侧栏尺寸写入接口。原清单中的“强设首次宽度”改为原生可拖动宽度，避免干扰其他插件和用户保存的布局。

## C. 排版节奏

- [x] 保留用户已有字号、字体、行距；新增“应用推荐排版”，仅在主动点击时调整行距、行长和对齐。
- [x] 自动行长限制为中文约 32 字、拉丁文约 72 字；手动数值沿用原有拉丁字符含义，窄屏保持自适应。
- [x] 调整段间距与标题层级；保留引用和代码样式，FB2 诗行单独处理。
- [x] AI 回答采用 Obsidian 正文字号并限制在 15–18px，继续使用无重背景的正文式回答。
- [x] 阅读设置分段选项改为原生按钮，提供分组名称、选中状态及键盘焦点。

## D. 找回阅读位置

- [x] 目录、搜索、划线、页码和文内引用跳转提供“返回刚才的位置”；普通翻页不制造返回记录。
- [x] 返回基于内容锚点，不依赖可能变化的屏幕页码；跨书清理返回点。
- [x] 保留段落闪现提示；返回按钮支持键盘，置于底部控件区域并暂时让出进度标签位置。
- [x] EPUB/FB2 显示当前章节与进度；PDF 页码及跳转范围使用原文件页数，不随缩放变成屏幕页数。

## E. 选文与笔记

- [x] 鼠标拖选期间隐藏浮动菜单，松开后显示；触屏保留原生选择手柄。
- [x] 菜单在阅读视口内避让选区，窄屏限制宽度并允许动作换行。
- [x] 问 AI 后以独立 CSS Highlight 保留原文定位；重新排版后按内容重建，替换/移除来源或离开书籍时清理。
- [x] 已有划线点击即可进入批注编辑；保存回答后显示“已保存 · 打开笔记”，不自动打开标签或关闭对话。
- [x] 保存按钮写入期间禁用，成功后再次点击只打开既有笔记，不重复创建。

## F. PDF 独立操作

- [x] 提供整页、适合宽度与自定义百分比缩放；百分比按钮打开菜单，宽度模式随重排更新。
- [x] 滚轮/双指缩放以指针/手势中心为锚点；按钮缩放围绕视口中心。滚动范围边缘仍遵循浏览器边界约束。
- [x] 增加手形拖动模式与鼠标中键临时拖动；拖动后的点击被消费，不误翻页或打开图片。
- [x] 保留固定尺寸占位和 PDF 文字层；图像延迟加载不改变页面尺寸，原文页码和全文问答保持独立。
