- 独立工作树 `npm ci`。
- `npm test`：119/119，通过 6 项新增回归。
- `npm run check:i18n`：1,161 个英文键有中文覆盖。
- `npx eslint src/ --max-warnings 0`、`npm run build`、`npm run verify:release` 通过。

- 实际键盘输入 `monospace` 后，预览和正文计算字体均为 `monospace`；常驻按钮在工具栏外，点击下一页有效。默认模式恢复为原来的底部工具栏按钮，没有重复创建按钮。

## 范围与待验证项

- #17 采用 issue 正文列出的「手动填写字体名称 / font-family」方案；本次不自动枚举系统字体，也不导入 TTF/OTF/WOFF 文件。用户需先在系统安装所用字体，设备缺少该字体时浏览器使用备用字体。
- #19 未提供原始 PDF，无法对报告者的那本书逐页比对。截图已检查，旧版路径已核实；新增样本验证不能替代原书复验，因此不自动关闭 #19。
- 当前 Obsidian 有另一条开发/验收流程在操作，本次未覆盖其安装或配置。`verify:release` 的 `installVerified` 为 false；上述浏览器检查不冒充完整 Obsidian 安装验收。
- 合并和正式发布前仍需在独立 Obsidian vault 验收桌面/移动阅读器、跨重启设置恢复和阅读锚点；不应以 CI 通过替代这些检查。
